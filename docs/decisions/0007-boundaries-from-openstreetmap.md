# 0007. 지역 선택 지도의 행정경계는 OpenStreetMap 자료로 만든다

## 맥락
여행 지역 선택 화면은 시도·시군구 윤곽을 지도 위에 그린다. 예전 윤곽 파일은 출처와 이용조건을 원문으로 확인할 수 없어 공개본에 둘 수 없었다. 공개본에는 이용조건이 원문으로 확인되는 자료만 담는다.

## 선택지
1. 공공 포털의 센서스 경계: 포털 목록은 "이용허락범위 제한 없음"이었지만, 실제로 내려받는 페이지는 "저작자표시-비영리-변경금지"였다. 근거가 서로 어긋나고, 변경금지라면 단순화할 수 없다.
2. geoBoundaries 시군구: 목록은 CC BY 3.0 이라고 하지만, 원 제공처의 이용조건은 지도 자료의 저작권을 따로 유보한다.
3. Natural Earth 광역: 퍼블릭 도메인이지만 시도까지만 있다.
4. OpenStreetMap: ODbL 1.0 원문이 복사·배포·변경을 출처 표시와 같은 라이선스 조건으로 허용한다.
5. 윤곽 없이 목록으로만 고른다.

## 결정
4. `scripts/build_geo.py` 가 OSM 행정경계를 받아 앱 지역 목록에 맞추고, 영해까지 그려진 해안 쪽 경계를 OSM 해안선의 육지 다각형으로 잘라 단순화한다.

## 결과
- 두 GeoJSON 은 MIT 가 아니라 ODbL 을 따른다. `assets/geo/LICENSE-ODbL.md` 에 고지하고, 지도 위에 "© OpenStreetMap contributors" 를 표시한다.
- 앱 지역 목록(서버 표기)과 OSM 의 개편된 구역이 어긋나는 두 곳은 윤곽 없이 목록으로만 고른다. 자세한 한계는 [data.md](../data.md).
- 코드는 행정표준코드가 아니라 앱 안의 합성 번호다. 시군구 코드 앞자리가 시도 코드인 규칙을 시험이 고정한다.
