# 0006. 앱 글꼴은 저장소에 두지 않고 빌드 때 받는다

## 맥락
앱 글꼴 Pretendard(SIL OFL 1.1)는 굵기 100~900 을 모두 쓰는 6.7MB 가변 글꼴이다. 공개 저장소는 1MB 이상 파일을 히스토리에 두지 않기로 했다. OFL 은 예약 글꼴 이름(Pretendard)이 있어, 글꼴을 고친 판은 그 이름으로 배포할 수 없다.

## 선택지
1. 한국어 완성형·라틴만 남긴 서브셋을 넣는다. 가변 글꼴은 최소로 줄여도 1MB 를 넘어 정적 굵기별 파일로 나눠야 하고, 고친 판이라 글꼴 이름도 바꿔야 한다.
2. 원본을 빌드 때 받는다. 해시를 고정한다.
3. 번들 글꼴을 빼고 시스템 글꼴을 쓴다.
4. 크기 한도에 예외를 둔다.

## 결정
2. `scripts/fetch_fonts.sh` 가 배포처의 태그 고정 주소에서 글꼴과 라이선스 원문을 받아 sha256 을 확인한다. 원본 그대로라 이름을 바꾸지 않는다.

## 결과
- `flutter pub get`·`flutter test`·빌드 전에 받기를 먼저 해야 하고, 그때 네트워크가 필요하다. CI 도 같은 순서로 돈다.
- 라이선스 원문(`OFL.txt`)이 글꼴과 함께 앱 자산에 실린다.
