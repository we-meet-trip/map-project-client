# 0005. 카카오 로그인은 카카오 SDK 의 앱 간 전환으로 한다

## 맥락
카카오 로그인 콘솔은 https 복귀 주소만 받는다. 그래서 처음에는 서버가 https 콜백으로 인가 코드를 받은 뒤 앱의 커스텀 스킴으로 되돌려 주는 방식(서버 경유 302)을 썼다. 이 방식은 로그인 도중 브라우저를 거치는데, 기기의 브라우저 트래픽만 다른 경로로 내보내는 개인정보 보호 기능을 쓰면 브라우저와 카카오톡 앱의 출발 IP 가 달라져 카카오가 로그인을 끊었다(커밋 설명 기준).

## 선택지
1. 서버 경유 302 를 유지하고 실패를 안내한다.
2. 카카오 Flutter SDK 로 카카오톡 앱에 곧장 전환해 로그인하고, 결과를 `kakao{네이티브 앱 키}://oauth` 로 받는다.

## 결정
2. 카카오톡이 없을 때만 카카오계정(브라우저) 로그인으로 넘어가고, 거기서 실패했을 때 사용자가 해 볼 조치를 안내한다.

## 결과
- 복귀 감시 타이머·요청 짝짓기 난수·제한 시간 같은 브라우저 복귀 장치를 모두 걷어 냈다.
- 카카오톡 설치 확인을 위해 iOS 앱 실행 허용 목록에 카카오 스킴을 밝혀 둔다(`Info.plist`).
- 네이티브 앱 키가 빌드값으로 필요하다(`CLIENT_KAKAO_NATIVE_APP_KEY`). Android 운영 빌드는 키가 없으면 빌드를 멈춘다.
