# 0004. 동의는 서버 기록이 기준이고, 판은 서버 값을 그대로 쓴다

## 맥락
서비스 이용 동의(약관·개인정보·연령)와 외부 AI 전송 동의는 서버가 요청마다 확인한다. 앱만 동의를 기억하거나 정책 판을 상수로 들고 있으면, 서버와 판정이 어긋나 동의한 사용자가 거절당하거나 앱 전체가 잠긴다.

## 선택지
1. 앱이 동의 상태와 판을 들고 판단한다.
2. 서버가 동의를 기록하고 판을 정한다. 앱은 기록을 만들고, 서버가 준 판을 되돌려 보낸다.

## 결정
2. 외부 AI 전송은 기능(추천·Vision·리뷰 요약)마다 따로 묻고, 기본은 동의 없음이다. 서버 기록에 실패하면 동의로 치지 않는다. 철회는 서버 호출이 실패해도 앱 안의 차단을 되돌리지 않는다.

## 결과
- 판이 바뀌어도 앱을 다시 낼 필요가 없다. 앱은 판의 형식만 확인한다(`^[A-Za-z0-9][A-Za-z0-9._-]{0,31}$`).
- 서버가 판을 올리면 기존 사용자는 새 판에 다시 동의할 때까지 서비스 요청이 막힌다. 동의 화면은 열린다.
