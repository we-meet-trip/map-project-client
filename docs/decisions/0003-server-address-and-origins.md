# 0003. 서버 주소는 빌드에 굽지 않고, 믿을 origin 을 따로 정한다

## 맥락
설치본은 오래 살지만 서버 주소는 바뀐다. 동시에 로그인 토큰은 요청을 보내는 서버 주소를 따라가므로, 주소를 바꿀 수 있는 경로가 곧 토큰이 새는 경로가 된다.

## 선택지
1. 서버 주소를 빌드값으로 굽는다.
2. 시작할 때 고정된 위치의 원격 설정 문서에서 주소를 읽고, 마지막 성공값을 기기에 남긴다.
3. 2 에 더해, 릴리스 빌드는 미리 정한 https origin 목록에 있는 주소만 믿는다.

## 결정
3. 정하는 순서는 빌드값(개발용) → 원격 설정 → 기기 캐시 → 로컬 기본값이다. 릴리스 빌드는 `CLIENT_API_ALLOWED_ORIGINS` 에 있는 https origin 만 쓰고, 운영 빌드는 이 목록을 반드시 직접 준다. 공개본의 기본값에는 서버 주소가 없다.

## 결과
- 원격 설정 문서는 선택이다. 주지 않으면 원격 조회 없이 로컬 서버를 본다.
- 원격 조회는 첫 화면 전에 일어나므로 3초로 끊고, 실패하면 뒤에서 간격을 늘려 다시 묻는다.
- 판정은 `lib/core/config/endpoint_policy.dart` 한 곳에 있고 시험이 고정한다.
